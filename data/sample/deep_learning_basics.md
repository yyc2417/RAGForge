# 深度学习基础

## CNN 卷积神经网络是什么？

卷积神经网络（Convolutional Neural Network）是处理网格状数据（如图像）的神经网络。核心操作是卷积：用小的卷积核在输入上滑动，提取局部特征。

**关键组件**：
1. **卷积层**：局部感受野 + 权重共享，大幅减少参数量
2. **池化层**：Max Pooling / Average Pooling 降采样，提供平移不变性
3. **全连接层**：通常在末尾做分类输出

经典网络演进：LeNet → AlexNet → VGG → ResNet。ResNet 的残差连接（Residual Connection）解决了深层网络梯度消失问题，让上百层网络成为可能。

## RNN 和 LSTM 有什么区别？

循环神经网络（RNN）按时间步展开处理序列，隐藏状态在步与步之间传递。但普通 RNN 存在梯度消失/爆炸，难以记忆长距离依赖。

LSTM（长短期记忆网络）引入门控机制解决该问题：
1. **遗忘门**：决定丢弃哪些旧记忆
2. **输入门**：决定写入哪些新信息
3. **输出门**：决定输出哪部分记忆

GRU 是 LSTM 的简化版，把遗忘门和输入门合并为更新门，参数更少、速度更快，效果接近。

## 批归一化（Batch Normalization）的作用？

批归一化对每个 mini-batch 的激活值做标准化（减均值除标准差），再通过可学习的缩放和平移参数恢复表达能力。

**三个主要作用**：
1. 缓解内部协变量偏移，使各层输入分布更稳定
2. 允许更大的学习率，加快收敛
3. 有轻微正则化效果

注意：小 batch size 时 BN 统计量不稳定，可换用 LayerNorm（Transformer 采用）或 GroupNorm。

## 学习率调度有哪些常用策略？

1. **Step Decay**：每隔固定 epoch 学习率乘以 0.1
2. **Cosine Annealing**：学习率随训练余弦下降到接近 0，大模型微调常用
3. **Warmup**：训练初期从极小学习率线性升温（如前 1000 步），避免初始大步长破坏预训练权重
4. **OneCycle**：先升后降，一次周期内完成训练

实践建议：微调预训练模型时，底层用更小的学习率，顶层用较大学习率（分层学习率 / 差分学习率）。

## 什么是迁移学习？

迁移学习把在大规模数据（如 ImageNet、海量文本）上预训练的模型，迁移到目标任务上微调（Fine-tuning）。

**两种典型做法**：
1. **特征提取**：冻结预训练骨干，只训练新增的分类头，数据少时适用
2. **全量微调**：解冻全部参数用小学习率训练，数据较多时适用

NLP 领域的范式演进：Word2Vec 静态词向量 → BERT 预训练+微调 → GPT 大规模指令微调（Prompting / In-context Learning）。
