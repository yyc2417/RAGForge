# 机器学习常见问题

## 什么是过拟合？

过拟合（Overfitting）是指模型在训练数据上表现很好，但在未见过的数据上表现差。模型"记住"了训练数据的噪声和细节，而不是学到一般性规律。

**识别方法**：训练集准确率高，验证集准确率低（泛化能力差）。

**解决方法**：
1. **增加训练数据**：更多数据让模型学到更一般的规律
2. **正则化**：L1（Lasso）和 L2（Ridge）正则化限制模型复杂度
3. **Dropout**：随机丢弃神经元，防止过依赖某些特征
4. **早停（Early Stopping）**：验证集损失不再下降时停止训练
5. **交叉验证**：用 K-Fold 交叉验证评估模型泛化能力

## 什么是欠拟合？

欠拟合（Underfitting）是指模型过于简单，无法捕捉数据中的规律。

**识别方法**：训练集和验证集准确率都很低。

**解决方法**：
1. **增加模型复杂度**：更深的网络、更多的特征
2. **减少正则化**：降低正则化系数
3. **增加训练时间**：模型可能还没收敛

## 梯度下降是什么？

梯度下降（Gradient Descent）是优化模型参数的核心算法。原理是沿着损失函数梯度的反方向更新参数，逐步逼近最小值。

公式：`参数 = 参数 - 学习率 × 梯度`

三种变体：
- **批量梯度下降（BGD）**：用全部数据计算梯度，精确但慢
- **随机梯度下降（SGD）**：每次用一个样本，快但波动大
- **小批量梯度下降（Mini-batch）**：折中方案，常用 batch_size=32/64/128

常见优化器：
- **Adam**：自适应学习率，大部分场景的首选
- **SGD + Momentum**：在收敛后期可能比 Adam 泛化更好
- **AdamW**：Adam + 权重衰减，大模型训练常用

## 什么是 Transformer？

Transformer 是 2017 年 Google 提出的神经网络架构，论文《Attention Is All You Need》。它完全基于注意力机制，抛弃了传统的循环结构（RNN/LSTM）。

**核心组件**：
1. **自注意力机制（Self-Attention）**：每个 token 关注所有其他 token，计算 Query、Key、Value 的加权和
2. **多头注意力（Multi-Head Attention）**：并行多个注意力头，捕获不同维度的关系
3. **位置编码（Positional Encoding）**：给输入加上位置信息（因为自注意力本身不包含顺序信息）
4. **前馈网络（FFN）**：每层的非线性变换

**为什么重要**：
- 支持并行计算（不像 RNN 必须顺序处理）
- 长距离依赖处理能力强
- 是 GPT、BERT、LLaMA 等大模型的基础架构

## Embedding 是什么？

Embedding（嵌入）是将离散数据（如文本、类别）映射为连续向量空间中的稠密向量。

```
"猫" → [0.23, -0.15, 0.87, ..., 0.42]  (768维向量)
"狗" → [0.21, -0.12, 0.85, ..., 0.39]  (语义相似，向量也接近)
"汽车" → [-0.56, 0.33, -0.21, ..., 0.71]  (语义不同，向量距离远)
```

**应用场景**：
- 文本检索（RAG 系统的核心）：将查询和文档都转为向量，用余弦相似度找最相关的
- 推荐系统：用户和物品都嵌入向量空间
- 聚类分析：在向量空间中发现自然分组

**常见 Embedding 模型**：
- OpenAI text-embedding-3-small/large
- BGE 系列（中文效果好）
- all-MiniLM（轻量，适合原型）

## 精确率、召回率和 F1 分数

这三个指标用于评估分类模型：

- **精确率（Precision）**= TP / (TP + FP)：预测为正的样本中，真正为正的比例。"预测的准不准？"
- **召回率（Recall）**= TP / (TP + FN)：实际为正的样本中，被正确预测的比例。"找的全不全？"
- **F1 分数** = 2 × Precision × Recall / (Precision + Recall)：精确率和召回率的调和平均值

在 RAG 系统中，这些指标用于评估检索质量：检索到的文档中有多少是真正相关的（精确率），相关文档中有多少被检索到了（召回率）。
